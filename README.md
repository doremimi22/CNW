# CNW

Dự án thực hành môn **Công nghệ Web**, phát triển theo mô hình mã nguồn mở và có đầy đủ hồ sơ cộng đồng (giấy phép, hướng dẫn đóng góp, quy ước ứng xử, chính sách bảo mật).

## 📌 Giới thiệu

Dự án này được xây dựng để thực hành các kiến thức về phát triển web và quy trình làm việc cộng tác trên GitHub.

## ✨ Tính năng chính

- Tính năng 1: Hiển thị danh sách nhạc yêu thích
- Tính năng 2: Tạo album nghe nhạc thường xuyên
- Tính năng 3: ...

## 🛠️ Công nghệ sử dụng

- Ngôn ngữ: Java

## 🚀 Cài đặt và chạy thử

```bash
# 1. Clone kho lưu trữ
git clone https://github.com/doremimi22/CNW.git

# 2. Di chuyển vào thư mục dự án
cd CNW

# 3. Chạy dự án (thay bằng lệnh phù hợp)
# Ví dụ: mở file index.html trong trình duyệt
```
